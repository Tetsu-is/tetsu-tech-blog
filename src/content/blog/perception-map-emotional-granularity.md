#### 心の階調数

工学出身の方以外は階調数という言葉に聞き馴染みがないかもしれません。階調数は段階の細かさです。
幸せと絶望の 2 段階では感情の起伏が大きく疲れてしまいます。

```
あたいが二つしかない時の波
```

私は辛いことが起きた時に落ち込む前に「評価」が入る気がしていて、どれくらい辛いかを決めているんじゃないかなーと思ってます。

```
重みの評価をするスライド
```

階調数を大きくすれば感情の波は滑らかになり振れ幅を小さくできますし、傾向を掴みやすいです。

```
滑らかなグラフ
```
